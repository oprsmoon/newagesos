Under The Hood

Real math.
Not vibes.

Every dashboard number traces back to one of these engines — nothing hard-coded, nothing placeholder.

🎲
ENGINE 01 / CTS

Civic Trust Score

Bayesian Beta-Bernoulli posterior per H3 hex with exponential recency decay — trust updates live, resists one-report swings, fades old evidence.

CTS = clip( E[θ]·M_time·M_infra , 0, 1 )
📈
ENGINE 02 / IRS

Incident Risk Score

Deterministic weighted composite — fully explainable to a judge, a Guardian, or a court. CTS feeds directly in as location risk.

IRS = 10·[ w₁S + w₂P + w₃(1−CTS) + w₄E − w₅C ]
🛡️
ENGINE 03 / DISPATCH

Guardian Assignment

Ranks responders by inverse travel-time × personal reliability − load penalty, gated on availability and IRS ≥ 6.0.

g* = argmax[ v₁D⁻¹ + v₂R_g + v₃C_g − v₄L(g) ]
👤
ENGINE 04 / RELIABILITY

Reporter Reliability

Laplace-smoothed precision per reporter — three high-trust vouches outweigh ten sock-puppets. New accounts start at R = 0.5, never 1.

R_u = (TP_u + 1) / (TP_u + FP_u + 2)
🔐
ENGINE 05 / EVIDENCE

SHA-256 Evidence Vault

Audio recorded on-device, chunk-hashed client-side with timestamps — a tamper-evident chain of custody from the first second.

digest = SHA-256(chunk ‖ timestamp)
🗺️
ENGINE 06 / HEATMAP

H3 Risk Grid + News RSS

Live crime FIRs aggregated via backend proxy onto 5km hex clusters — patterns visible before they become incidents.

RSS proxy → H3(5km) → prior seeding α₀,β₀
