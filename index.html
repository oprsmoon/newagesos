📱 The 4-Digit Room Code — Critical for Multi-Device Testing

The room code (a random 4-digit code — auto-generated if empty) connects multiple devices into one live simulation room. Here's how to test properly:

🖥️
Device 1 — Operator Dashboard

Open operator.html?pin=1234 on a laptop/desktop first. This is the command center.

📱
Device 2 — Citizen App index.html?pin=1234 on a phone. This is the victim/responder.

🛡️
Device 3+ — Guardian App (for Guardian Mode)

Open index.html?pin=1234 on additional phones. Enable Guardian Mode in each. Minimum 3 devices total for Guardian testing.

🔐 Required Permissions — Allow All

  • Location (GPS) — Required for SOS location, Guardian dispatch, live tracking
  • Microphone — Required for audio evidence recording (SHA-256 hashed)
  • Camera — Required for video conference (Jitsi)
  • Notifications — Required for SOS alerts, Guardian dispatches

Without these, core features won't work. Browser will prompt on first use.

🧪 Recommended Test Flow

  1. Open Operator Dashboard first (Device 1)
  2. Open Citizen App (Device 2) — press SOS
  3. Watch Operator Dashboard receive alert
  4. Open Guardian App (Device 3) — go on Standby
  5. Watch Guardian get dispatched, join video conference
  6. Complete mission → see rating → CTS updates
